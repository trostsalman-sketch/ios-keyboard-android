# iOS Клавиатура для Android

Клавиатура в стиле iPhone для Android, фиолетовый дизайн.

## Скачать

**[ios-keyboard.apk](https://github.com/trostsalman-sketch/ios-keyboard-android/releases/latest/download/ios-keyboard.apk)** — последняя сборка.

## Установка

1. Скачайте APK на телефон и откройте его. Если Android спросит, разрешите установку из этого источника.
2. Откройте приложение «iOS Клавиатура».
3. Шаг 1: включите клавиатуру в настройках.
4. Шаг 2: выберите её в списке клавиатур.
5. Готово, можно печатать.

## Возможности

- Раскладки русская (ЙЦУКЕН) и английская (QWERTY), цифры и символы как на iPhone
- 🌐 — смена языка, удержание 🌐 — выбор другой клавиатуры
- Двойное нажатие ⇧ — Caps Lock
- Удержание «е» → «ё», «ь» → «ъ»
- Два пробела — точка
- Автозаглавная буква в начале предложения
- Звук и вибрация клавиш, светлая и тёмная фиолетовая тема
